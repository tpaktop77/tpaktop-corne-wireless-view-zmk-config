## Context

См. причину изменения в [proposal.md](proposal.md). Аппаратная проверка после merge PR #5 показала дефект, который не обнаруживается компиляцией Devicetree: `RUSSIAN = 9` остаётся активным базовым слоем, а открываемый thumb-клавишей `NAVIGATION = 3` имеет меньший приоритет. ZMK разрешает binding из активного слоя с наибольшим индексом, поэтому русская буква продолжает маскировать Navigation. Тот же дефект потенциально затрагивает `NUMBERS`, `FUNCTION` и `SYSTEM_BT`.

Именованные константы не задают индекс сами по себе: их значения должны совпадать с порядком дочерних nodes в `keymap`. Все ссылки уже используют имена слоёв, поэтому согласованная перенумерация ограничивает изменение архитектуры и не требует переписывать bindings.

Та же аппаратная проверка показала частые false positive Auto Shift при 250 мс. Пользователь разрешил увеличить порог на 30–50 мс; выбран верхний предел 300 мс, потому что ложные срабатывания описаны как частые. Это относится только к `&as`, а не к отдельному быстрому повторному tap у `&lt`.

## Goals / Non-Goals

**Goals:**

- Обеспечить фактически одинаковое поведение шести thumb-позиций на `GRAPHITE`, `QWERTY` и `RUSSIAN`.
- Выразить порядок слоёв как топологический порядок: base ниже overlay, дочерний overlay выше родительского.
- Сохранить существующее содержимое слоёв и все именованные переходы.
- Добавить проверку инварианта, который успешная сборка сама по себе не подтверждает.
- Снизить чувствительность Auto Shift единым порогом для Graphite, QWERTY и Russian.

**Non-Goals:**

- Изменение раскладки или bindings `NAVIGATION` и других overlay-слоёв.
- Настройка tap-hold таймингов, overlap combo или switches.
- Изменение русских букв, Symbols, Smiles, набора Auto Shift bindings, Caps Word либо переключения языка.
- Архивация смерженного OpenSpec change `migrate-russian-layers` до завершения аппаратных тестов.

## Decisions

### 1. Поместить все base layers перед всеми доступными с них overlays

Итоговый порядок layer nodes и соответствующих констант:

| Индекс | Слой | Причина позиции |
| ---: | --- | --- |
| 0 | `GRAPHITE` | обязательный default fallback |
| 1 | `QWERTY` | альтернативная английская база |
| 2 | `RUSSIAN` | русская база ниже всех thumb overlays |
| 3 | `NUMBERS` | общий overlay поверх любой базы |
| 4 | `NAVIGATION` | общий overlay поверх любой базы |
| 5 | `FUNCTION` | общий overlay поверх любой базы |
| 6 | `VIM` | дочерний overlay выше `NUMBERS` и `FUNCTION` |
| 7 | `SYMBOLS` | английский overlay выше английских баз |
| 8 | `SMILES` | дочерний overlay выше `SYMBOLS` |
| 9 | `RUSSIAN_SYMBOLS` | русский overlay выше `RUSSIAN` |
| 10 | `RUSSIAN_SMILES` | дочерний overlay выше `RUSSIAN_SYMBOLS` |
| 11 | `SYSTEM_BT` | общий momentary overlay поверх всех рабочих слоёв |
| 12–14 | `STUDIO_EXTRA_1`–`3` | существующий reserved-диапазон Studio |

Такой порядок выполняет все существующие зависимости `base → overlay` и `parent overlay → child overlay`, сохраняя `GRAPHITE = 0` и Studio 12–14.

Альтернатива сохранить `RUSSIAN = 9` и поднять только `NAVIGATION` отвергнута: она оставила бы тот же дефект для Numbers, Function и System и нарушила бы вложенные зависимости Symbols/Smiles. Альтернатива продублировать overlay-содержимое на русских слоях отвергнута как источник расхождений.

### 2. Не менять thumb bindings

Bindings позиций 36–41 остаются побайтно эквивалентны текущей схеме; на позиции 37 сохраняется намеренное языковое различие `SYMBOLS`/`RUSSIAN_SYMBOLS`. Исправляется исключительно возможность целевого слоя стать наблюдаемым поверх активной базы.

Использовать `&trans` вместо явных русских thumb bindings нельзя: позиция 37 унаследовала бы английский `SYMBOLS`, а сам более низкий общий overlay всё равно не мог бы перекрыть `RUSSIAN` без исправления индексов.

### 3. Проверять одновременно значения констант и порядок nodes

Статическая проверка SHALL сопоставлять последовательность `#define` с последовательностью layer nodes и отдельно подтверждать неравенства для переходов:

- `SYSTEM_BT`, `NUMBERS`, `FUNCTION`, `NAVIGATION` выше `RUSSIAN`;
- `VIM` выше `NUMBERS` и `FUNCTION`;
- `SMILES` выше `SYMBOLS`;
- `RUSSIAN_SMILES` выше `RUSSIAN_SYMBOLS`, который выше `RUSSIAN`.

После этого выполняются `git diff --check`, строгая OpenSpec validation и обе сборки. Аппаратный test matrix остаётся обязательным, потому что build доказывает корректность DTS, но не удобство и фактическую tap-hold активацию.

### 4. Увеличить только Auto Shift tapping term до 300 мс

Параметризованный behavior `&as` остаётся единым для английских и русских букв, но его `tapping-term-ms` меняется с 250 на 300 мс. Короткое нажатие до нового порога продолжает отправлять обычную букву, более длительное — Shift+букву. `quick-tap-ms = 0` у Auto Shift не меняется.

Отдельный `&lt.quick-tap-ms = 250` сохраняется: он нужен для повторения tap-кодов thumb layer-tap и не является чувствительностью Auto Shift. Вариант 280 мс рассматривался как нижняя граница запрошенного увеличения, но 300 мс выбран из-за частоты наблюдаемых false positive и более удобного для измерения круглого порога.

## Risks / Trade-offs

- [Константы и фактический node order расходятся] → Проверять обе последовательности до сборки и документировать единую таблицу индексов.
- [Ссылка на слой осталась числовой] → Искать layer behaviors и combo scopes, подтверждая использование именованных констант.
- [Перестановка меняет Studio metadata] → Сохранить display names и reserved indices 12–14, собрать левую половину со Studio snippet.
- [Успешная сборка снова скрывает runtime-регрессию] → Добавить отдельные ручные тесты удержаний позиций 36–40 на `RUSSIAN` по USB и BLE.
- [Изменение случайно затрагивает Navigation] → Разрешить только перемещение node и именованного индекса; сравнить сами bindings до и после.
- [300 мс делает намеренный Shift медленнее] → Зафиксировать новый порог в test matrix и отдельно проверить быстрый обычный набор и намеренные удержания по USB/BLE.
- [Настройка Auto Shift случайно меняет thumb tap-hold] → Проверить, что `&lt.quick-tap-ms` остаётся 250 мс, а меняется только `&as.tapping-term-ms`.

## Migration Plan

1. Создать отдельную ветку от merge-коммита PR #5 и новый OpenSpec change.
2. Перенумеровать именованные слои и переставить layer nodes по единой таблице, не меняя bindings.
3. Увеличить `&as.tapping-term-ms` до 300 мс, не меняя `&lt` и Auto Shift bindings.
4. Обновить layout, migration matrix и test matrix с новым порядком, новым порогом и регрессионными тестами.
5. Выполнить структурные проверки, `git diff --check`, строгую OpenSpec validation и собрать обе половины.
6. Создать отдельный PR и передать владельцу тест удержаний каждого thumb на `RUSSIAN` и Auto Shift 300 мс.

Rollback выполняется revert одного исправляющего PR. Данные во flash и формат OS/language state не меняются.
